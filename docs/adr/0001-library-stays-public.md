# The library stays public; accounts add features, never access

Every prompt and skill page on the site is readable and copyable without signing in, and accounts only add things a public page can't do (synced collections, private notes, a personal kit, personal MCP tools). We chose this over gating the library behind sign-up because search engines and AI assistants can only rank and cite pages they can fetch without a login, and because the same MIT-licensed files are already public on GitHub, so a wall would cost reach without protecting anything.
