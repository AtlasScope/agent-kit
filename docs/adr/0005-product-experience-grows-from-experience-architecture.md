# Product Experience grows inside the experience-architecture plugin

Agent Kit is adding the ability to judge and improve how a product looks, reads and flows, alongside how its pages connect. That work lives in the existing experience-architecture plugin as more skills (Walkthrough first, then Build), with the install id unchanged. The new skills use the same `ea` toolkit, evidence rules and judgment reference as Diagnose, Rethink and Verify, and a fifth plugin would make every run depend on two installs.

The skills are organised around one decision: how big a change each job in the product needs, from leave to reconceive (`references/levels.md`). Judgment about presentation stays in this plugin so it works with nothing else installed. Design Kit skills are used for craft when they are present.

Nothing in this direction is promoted on the site or in the prompt library until a comparison on apps it was not tuned on shows it choosing the right level and preserving what works more often than a plain agent does.
