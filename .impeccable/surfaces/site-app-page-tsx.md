# Homepage (site/app/page.tsx)

Scope: the homepage of atlasscope.dev, the Agent Kit site. Mode: Persuade.

Audience and job: developers who already use a coding agent and want to install; people new to coding agents who need a first step. Action: copy the install command, or follow "New to coding agents? Start here". Proof: the counts read from generated content, and the "tested with" version and date. Constraints: counts never hand-typed; logo never on the photo; reduced motion respected; real HTML text.

Memorable moment: the install command is usable in the first screen, on a solid strip under the horizon.

Settled by Austin on 2026-11-09: composition A (Horizon rail), picked from three HTML layouts on a Claude Design canvas because no image generator was available, so no generated comp or comp-diff exists for this build; muted grey is `#A3A6AD`; the photo is used as supplied.

On phones the install strip sits below the first screen until the phone header is shortened; the "Install Agent Kit" button jumps to it.

## Direction contract

THESIS: A developer can install Agent Kit without scrolling. The page refuses the centred headline over a picture with buttons underneath.

OWN-WORLD: Four colours only: ink `#0B0C12`, white, slate `#151821`, muted `#A3A6AD`. Lines are muted at reduced strength. No accent hue. Montserrat 600 headlines, Geist text, Geist Mono for commands. White pill for the one primary action, outlined pill for the second. The orbit photograph is the only image.

STORY: The visitor learns that Agent Kit is a library of written methods for coding agents, sees it is free and by AtlasScope, and either copies the install command or opens the beginner path.

FIRST VIEWPORT: 56px solid ink header with the AtlasScope lockup, a divider and "Agent Kit". Photo fills the frame anchored to the bottom, darkened to ink on the left. Eyebrow, 72px headline, 19px sentence and two pills hang from one left edge at 120px. A 112px solid ink strip along the bottom holds the agent tabs and install command with Copy on the left, three counts and the tested-with line on the right.
