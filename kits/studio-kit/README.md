# studio-kit

The **Studio Kit** plugin is in [`plugins/studio-kit`](plugins/studio-kit/README.md), with its README. That folder is what Claude Code, Codex and the plugin directory install.

## Install

```sh
claude plugin marketplace add AtlasScope/agent-kit
claude plugin install studio-kit@agent-kit
```

The [repository README](https://github.com/AtlasScope/agent-kit#install) covers cloud sessions, Codex and Cursor.
