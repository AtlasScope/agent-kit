# engineering-kit

The **Engineering Kit** plugin is in [`plugins/engineering-kit`](plugins/engineering-kit/README.md), with its README. That folder is what Claude Code, Codex and the plugin directory install.

Credits, versions and licenses for the skills it bundles from other authors are in [THIRD_PARTY.md](THIRD_PARTY.md).

## Install

```sh
claude plugin marketplace add AtlasScope/agent-kit
claude plugin install engineering-kit@agent-kit
```

The [repository README](https://github.com/AtlasScope/agent-kit#install) covers cloud sessions, Codex and Cursor.
