# Site implementation contracts

This is the live interface between the website's shared components, not the old redesign workstream plan. [DESIGN.md](DESIGN.md) describes visual direction; code is the source of exact behavior.

- `site/app/styles/tokens.css` owns theme roles, type, space, motion and depth. `globals.css` imports shared styles in cascade order; `overrides.css` is last. Use existing primitives and route-local CSS; do not patch a shared bug with unrelated specificity.
- The Home/Install shared stage lives in `site/app/(stage)/`, `components/stage/` and the Horizon renderer. The interior shell and Install body share it. Coordinate changes to tokens, shared components and route transitions; there are no permanent lane owners.
- `components/install-choice.ts`, `components/stage/HomeHero.tsx` and `components/InstallPage.tsx` implement the shared clipboard handoff: Home copies the exact `INSTALL_MESSAGE` inside the click, navigates without waiting, records real success/refusal in session storage (`agent-kit:copied`), fires `agent-kit:handoff`; Install reads a fresh note (10 seconds) and shows truthful feedback or selects the text. Preserve this contract or change both ends together.
- Stage choreography depends on `.launch__go`, `main.inst`, `.inst__main` and its direct children, `.inst__msg`, `.inst__rim`, `.inst__trace` and the arrival/data hooks. Read actual code before changing them. Direct Install visits work independently.
- `lib/copy.ts`, `lib/site.ts`, `CopyButton.tsx` and shared Cards/FloatingCopy are consumed across page families. Preserve copy payloads, install commands, IDs, public URLs/redirects, Markdown twins, crawler files and metadata unless intentionally changing those contracts. Clipboard refusal must still provide a manual path.
- The logo component is generated from `design/atlasscope/source/export_site.py`. Horizon assets and fallbacks have source and generation instructions in `site/components/horizon/`.
- Keep semantic headings, keyboard focus, reduced motion, light/dark interiors and touch targets (44px where practical). Smoke tests each own a distinct local port; choose an unused one if adding a necessary test. Test relevant paths and devices, not every route for every change.
